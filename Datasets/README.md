# Datasets

This folder is intended for dataset documentation and small, shareable datasets used in portfolio projects.

## Good practices
- Record the original dataset source and license.
- Explain the meaning of important variables.
- Remove personal or confidential information.
- Do not upload private, sensitive, or restricted data.
- Prefer linking to the original source when redistribution is not permitted.

A dataset description should include its title, source, number of rows and columns (when known), and the project that uses it.
