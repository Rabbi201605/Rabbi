# Working on This Portfolio

Thank you for taking an interest in this portfolio.

## Standards
- Keep project descriptions accurate and distinguish completed work from planned work.
- Cite dataset sources and check their licenses before sharing data.
- Never commit passwords, API keys, private records, or identifiable respondent data.
- Use clear file names and add comments where they help explain the analysis.
- Explain statistical assumptions, effect sizes, and limitations.
- Prefer reproducible scripts and document how to run them.

## Before Publishing a Project
- [ ] Confirm the dataset source and reuse permission.
- [ ] Document the variables and coding scheme.
- [ ] Check missing values and duplicates.
- [ ] Verify calculations and statistical interpretations.
- [ ] Remove private or sensitive information.
- [ ] Update the project README with reproducible instructions.
